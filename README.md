# yoelgal/tap

Homebrew casks for my Mac apps.

```sh
brew install --cask yoelgal/tap/<cask>
```

| Cask | App | Source | Website |
| --- | --- | --- | --- |
| `openlookaway` | OpenLookAway: a free, open-source break reminder for your Mac | [yoelgal/openlookaway](https://github.com/yoelgal/openlookaway) | [lookaway.yoelgal.com](https://lookaway.yoelgal.com) |
| `notes-thing` | Notes Thing: record anything and take notes that land in the on-device transcript at the second you wrote them | [yoelgal/notes-thing](https://github.com/yoelgal/notes-thing) | [notesthing.yoelgal.com](https://notesthing.yoelgal.com) |

Both apps are ad-hoc signed rather than notarized; each repo's README explains what that means and how to install without Homebrew.
